These are development associations, not causal explanations of hidden reasoning.

## Review sampling and labels

Stable SHA256 ranking includes seed 20261013, study ID, dataset and group. Main sampling selects ten groups per dataset from the existing mixed population, independently of outcomes/acceptance. All five scheduled rewrites remain represented; unavailable pairs are not replaced. The enriched manifest records up to twelve sentinel pairs and available neutral counterparts, deduplicated by physical text unit. Enriched examples are illustrative only, never prevalence or span-selection evidence. Sampling ten MMLU tasks does not guarantee category coverage.

Reviewers receive **only** their `reviewers/<opaque-id>/pass1` directory. Analyst manifests and `sealed_mapping.json` must not accompany it. Static HTML/Markdown escapes all imported text, has no script/CDN/form, and uses a restrictive content policy. Anonymous candidate context and randomized Text A/B hide source direction, style, gold, judge identities and outcomes. Rhetoric can still reveal clues. A shared answer never supplies a semantic label.

Two people register separate identities. Registration/templates are not counted as actual reviews. Every reviewed row declares human/LLM/fixture origin, independence, outcome blinding, confidence, qualifications, task-substantive and meta-claim relations, internal support, task grounding, meta-claim support and exact evidence spans. `factual_premise_changes` describes **B relative to A**; analyses reverse added/removed when necessary. `text_a_*`/`text_b_*` fields and cue sets are also normalized before agreement. External facts remain uncertain without qualified review/references. No automatic semantic labels or online checking occur.

Locked first-pass rows cannot be overwritten. Both assigned independent passes must be locked for all available units before either pass2 is exported. Pass2 reveals actual saved clean/edited outputs, gold and direction, retaining observations separately from hypotheses. Third-person `adjudicate` appends an artifact-bound resolution without changing original labels. Confusion matrices/raw agreement retain disagreements; kappa is explicitly not estimated. Current origin/blinding assertions are auditable declarations, not proof of human identity or independence.

Reports show all scheduled main tasks/variants, missing and disputed labels, task-average complete-case estimates and a clearly marked scheduled-denominator lower bound. They separate enriched units and semantic attack-versus-neutral intersections. Main/enriched overlap is physically deduplicated and counted in the main panel. No inspected annotation may silently become training data.

## Exact-deletion child

`pact-rationale-span-intervention-001` freezes a separate copy of completed reviews. Before labels, the main manifest preselects up to eight accepted rewrites per dataset/style for `claimed_consensus` and `claimed_verification` (32 slots maximum). No replacement or success gate exists. Both independent, outcome-blinded human reviewers must approve identical cue/sham offsets and the six edit assertions. Every available review unit must have completed first-pass locks. LLM-origin reviews cannot unlock real execution. A third-person resolution can explain disagreements in the analysis; this first runner conservatively retains disputed original edit interpretations as ineligible rather than using an adjudicator to override either reviewer's edit approval.

Spans use exact Unicode code-point offsets, exact substrings and `digest(source_text)`. They must be disjoint and leave nonempty text. There is no automatic rewriting, truth inference, factual addition or invented sham. Explicit outcomes include unreviewed, no isolated cue, no adequate sham, substantive edit required and review disputed. Source and variant bytes/hashes remain separate. Missing controls reduce the plan; zero eligible units means not testable.

Explicit metadata-only Colab preflight uses both pinned native tokenizers. Removed token counts must differ by at most `max(8, ceil(.20 * cue_tokens))` under **each** judge. Each complete rendered prompt plus 512 output tokens must fit 8,192. Incompatible units are excluded as a whole without retuning. Exact model revisions, metadata/weight hashes, templates, BF16, SDPA, absence of adapters and decoding must match the parent. The new runtime is recorded, never represented as historical bitwise determinism; the new reference repeat diagnoses that limitation.

All three versions—fresh accepted-rewrite repeat, cue deletion, sham deletion—use J8/J14 and full selection/evidence selection/free synthesis. Parent prompt builders and perturbation invariance checks ensure only the selected wrong rationale changes. Seeds match across versions. Child dispatch IDs include the frozen plan and full version/request/source identities; no parent response is reused as the new repeat. Completed child calls resume by exact identity.

A separate user-created authorization JSON must bind plan, reviewed edits, checkpoint identities, request list and budget. The generated template has `approved=false`. **No real authorization was created during implementation.** Hard limits: 576 new judge attempts / 294,912 reserved output tokens; included two-unit smoke ≤36. All paid, generator, training, revision and teacher-forced budgets are zero. Attempts including ambiguous dispatch count; unsafe latest state never falls back or retries. Local ZIPs precede bounded verified Drive copies; snapshots use the existing compact `state.zip`/receipt storage format.

Primary outcome is cue-minus-sham correctness, paired and clustered by task group. Reports distinguish repeated source units from unique task groups, show new-reference/historical disagreement, reference-relative changes, option/ID/status distributions, missingness, secondary old/new failure subsets and resources. This human-assisted local mechanism test has residual wording/placement differences and is not a deployable defense.
